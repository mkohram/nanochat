# The GDH (Gated Double Helix) Architecture Specification

**Version:** 1.4 (Reconciled, no-forget-gate pass)

**Core philosophy:** A globally shared latent Sidecar interacts with layer-specific Local Streams via LoRA-adapted Read-Process-Write cycles. Write routing is state-independent, enabling per-layer parallel prefix-scan over sequence tokens.

---

## 1) Notation & constraints

- **Sequence/depth:**
  - `N`: sequence length
  - `M`: number of layers
- **Dimensions:**
  - `D`: model width
  - `R`: sidecar slot count
  - `r`: LoRA rank
  - `h`: write heads
  - `d_h = D / h`
- **Constraint:** `D % h == 0`

State variables:
- `L_t^(i) ∈ R^{1×D}`: token state at timestep `t`, layer `i`
- `S_{t,i} ∈ R^{R×D}`: sidecar state at timestep `t`, after layer `i`

Base conditions:
- `S_{t,0} = 0` for all `t` (layer-0 sidecar is zero)
- `S_{0,i} = 0` for all `i`

Boundary/reset mask for packed sequences:
- `b_t ∈ {0,1}`, where `b_t=1` means token `t` starts a new document/chunk segment.

---

## 2) Parameter taxonomy and scope

### Read-phase parameters

Global (shared across all layers):
- `W_global^(K_read), W_global^(V_read) ∈ R^{D×D}`

Layer-specific (shared across all tokens **within** layer `i`):
- `W_base,i^(Q_read) ∈ R^{D×D}`
- `A_i^(Q_read) ∈ R^{D×r}, B_i^(Q_read) ∈ R^{r×D}`
- `W_i^(O_read) ∈ R^{D×D}`
- `W_i^(g_read) ∈ R^{D×1}` (scalar read gate)

### Write-phase parameters

Global:
- `E_slots ∈ R^{R×D}` (learnable slot addresses)
- `W_global^(Q_write) ∈ R^{D×D}`

Layer-specific (shared across all tokens within layer `i`):
- `W_base,i^(K_write), W_base,i^(V_write) ∈ R^{D×D}`
- `A_i^(K_write), B_i^(K_write)` and `A_i^(V_write), B_i^(V_write)`
- `W_i^(O_write) ∈ R^{D×D}`

Effective projections:
- `W_eff,i^(Q_read) = W_base,i^(Q_read) + A_i^(Q_read) B_i^(Q_read)`
- `W_eff,i^(K_write) = W_base,i^(K_write) + A_i^(K_write) B_i^(K_write)`
- `W_eff,i^(V_write) = W_base,i^(V_write) + A_i^(V_write) B_i^(V_write)`

---

## 3) Initialization rules (no forget gate)

1. **Zero-init mixers:**
   - `W_i^(O_read) = 0`, `W_i^(O_write) = 0`
   - This makes GDH path initially no-op so model starts as baseline transformer.

2. **Symmetry breaking:**
   - `E_slots ~ N(0,1)`

3. **LoRA default:**
   - Standard LoRA-safe init (e.g., `A` random, `B` zero) so initial effective weights are near base.

4. **Mandatory segmented reset policy:**
   - Because updates are purely additive, sidecar accumulation must reset at document/chunk boundaries using `b_t` (defined in §5).

---

## 4) Forward pass at layer `i`, token `t`

### Phase I — Read

1) Local query:
- `x_read = RMSNorm(L_t^(i))`
- `Q_loc = x_read W_eff,i^(Q_read)`

2) Sidecar keys/values from prior-layer state:
- `Ŝ_{t,i-1} = RMSNorm(S_{t,i-1})`
- `K_mem = Ŝ_{t,i-1} W_global^(K_read)`
- `V_mem = Ŝ_{t,i-1} W_global^(V_read)`

3) Retrieval + gated injection:
- `Z_read = Softmax((Q_loc K_mem^T)/sqrt(D)) V_mem`
- `g_read = sigmoid(x_read W_i^(g_read)) ∈ R^{1×1}`
- `L̃_t^(i) = L_t^(i) + g_read * (Z_read W_i^(O_read))`

### Phase II — Process (standard pre-norm transformer)

- `Ĥ_t^(i) = L̃_t^(i) + SelfAttention(RMSNorm(L̃_t^(i)))`
- `L_t^(i,out) = Ĥ_t^(i) + FFN(RMSNorm(Ĥ_t^(i)))`
- With causal masking, `L_t^(i,out)` is prefix-conditioned on tokens `1..t`.

### Phase III — Parallel Write proposal

1) Local write vectors:
- `x_write = RMSNorm(L_t^(i,out))`
- `K_upd = x_write W_eff,i^(K_write)`
- `V_upd = x_write W_eff,i^(V_write)`

2) Static slot queries:
- `Q_slots = E_slots W_global^(Q_write)`

3) Multi-head routing (for each head `j=1..h`):
- Split `Q_slots, K_upd, V_upd` into width `d_h`
- `α_j = Softmax_dim=0((Q_slots,j K_upd,j^T)/sqrt(d_h)) ∈ R^{R×1}`
- `Δ_raw,j = α_j V_upd,j ∈ R^{R×d_h}`

4) Concatenate and mix:
- `Δ_raw = Concat_j(Δ_raw,j) ∈ R^{R×D}`
- `Δ_{t,i} = Δ_raw W_i^(O_write)`

---

## 5) Sequence-level accumulation (parallel scan with resets)

For each layer `i`, compute sidecar updates over tokens using **segmented prefix-sum** keyed by boundary mask `b_t`.

Define:
- `P_{t,i} = SegCumsum(Δ_{:,i}, b)_t`
  - i.e., cumulative sum over `t` that resets whenever `b_t=1`.

Then sidecar state is:
- `S_{t,i} = S_{t,i-1} + P_{t,i}`

This keeps computation parallel over `N` while preventing cross-document/chunk leakage.

---

## 6) Complexity

- Local self-attention: `O(M · N^2 · D)`
- GDH sidecar projections: `O(M · N · R · D^2)`
- GDH scan accumulation: `O(M · N · R · D)`

Total training compute remains dominated by transformer self-attention for long `N`.

Inference memory:
- KV cache: `O(M · N · D)`
- GDH running sidecar states (exact layer-consistent streaming): `O(M · R · D)`

> Note: claiming `O(R·D)` sidecar memory would require a different state-sharing scheme than this layer-indexed `S_{t,i}` definition.
